# Changelog

All notable changes to this project are documented here. The project follows
[Semantic Versioning](https://semver.org/) and
[Conventional Commits](https://www.conventionalcommits.org/).

## [0.1.0] – 2026-11-18

### Added
- Twelve skills: engineering-core, clean-code, software-design, testing,
  feature-to-code, understanding-code, git-workflow, build-and-ci,
  architecture-and-docs, logging, agentic-workflow, code-review.
- `code-reviewer` subagent for independent reviews.
- Session-start reminder hook.
- Git guard hook: blocks committing secrets, force-pushing to shared branches and
  non-conventional commit messages in repositories that use Conventional Commits.
- Copy-paste `CLAUDE.md` snippet for projects.
