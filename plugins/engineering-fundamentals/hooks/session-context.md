The engineering-fundamentals plugin is active. When a task involves writing,
changing, reviewing or planning code, load the matching skill before editing,
starting with `engineering-fundamentals:engineering-core`:
- clean-code (readability, smells, refactoring), software-design (SOLID, contracts,
  structure), testing (TDD, test data, mocks), feature-to-code (requirements to
  tests), understanding-code (unfamiliar code), git-workflow (commits, branches),
  build-and-ci (builds, pipelines, metrics), architecture-and-docs (decisions,
  diagrams, API docs), logging, agentic-workflow (autonomous multi-step work),
  code-review.
Core rules: understand before changing; tests first and visibly red; small steps;
never mix refactoring with behaviour changes; the full build must pass before work
is called done; keep it simple; follow the project's existing conventions; end with
a plain-language summary of what changed, why, how it was verified, and what is left.
